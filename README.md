# todoapp

A feature-rich Flutter Todo application with Firebase Authentication and Cloud Firestore integration, offering task management, priorities, categories, reminders, recurring tasks, time tracking, productivity insights, and cloud synchronization through a clean and responsive user interface.

## Features

- **User Authentication:** Secure registration and login using Firebase Authentication.
- **Cloud Synchronization:** Store and synchronize user-specific tasks using Cloud Firestore.
- **Task Management:** Create, edit, delete, pin, and complete tasks.
- **Priority Management:** Organize tasks by Low, Medium, and High priority levels.
- **Task Categories:** Categorize tasks into Work, Study, Personal, Health, Finance, and Other.
- **Smart Filtering:** Filter tasks by status, priority, due date, and completion.
- **Recurring Tasks:** Support for daily, weekly, and monthly recurring tasks.
- **Subtasks:** Divide larger tasks into smaller activities.
- **Time Tracking:** Track the time spent on individual tasks.
- **Notifications:** Receive task reminders and daily productivity summaries.
- **Insights and Analytics:** Monitor task completion and productivity progress.
- **Responsive UI:** Modern and user-friendly interface adaptable to different screen sizes.

## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Provider
- SharedPreferences
- Flutter Local Notifications

## Project Objective

To develop a practical and user-friendly productivity application that simplifies daily task management while providing secure authentication, cloud-based data storage, synchronization, and productivity tracking.
