Resolved issues (9/10/2026)
-----------------------------
Issues inside task_card.dart
-----------------------------
1. Bottom overflow by 6.2 px
The card content exceeded the height allocated by the GridView. Padding, spacing, text, tags, and the date row contributed to the height.

2. Nullable completionDate errors
The code accessed .year, .month, and .day without checking whether completionDate was null.

3. Unbounded-height layout assertion
The card used Spacer() inside a Column. Spacer relies on flex space, so the card must receive a finite height. An unbounded parent can cause RenderFlex children have non-zero flex but incoming height constraints are unbounded.

4. Excessive content height
The original padding and text sizes left insufficient vertical space in compact task cards, especially on smaller screens.

5. Potentially cramped date row
The date and remaining-time label shared one row, which could become cramped at narrow card widths.

6. Unused import
../utils/constants.dart was imported but not used in the revised file. This caused a warning rather than a runtime exception.

7. Missing popup-menu actions
The original popup menu provided only Edit and Delete. Other actions were missing from the menu.
